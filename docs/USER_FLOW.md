# 말결 사용자 흐름

```text
[홈 진입]
   ├─ 오늘의 단어/선별 단어 탐색
   │    ├─ 분위기 필터
   │    └─ 더 보기 → 최대 120개 탐색
   ├─ 즐겨찾기 보기
   │    ├─ v2 스냅샷 즉시 복원
   │    └─ v1 미확인 ID → 워커 조회 → v2 저장
   └─ 검색어 입력
        ├─ 선별 결과 즉시 표시
        └─ 전체 사전 워커 시작
             ├─ manifest/청크 로드
             ├─ 부분 결과 + 진행률 갱신
             ├─ 완료 → 전체 결과
             └─ 실패 → 선별 결과 유지 + 재시도

[단어 카드/오늘의 단어 선택]
   → URL에 ?word=<id> 추가
   → 접근 가능한 상세 다이얼로그
        ├─ 즐겨찾기 저장/해제
        ├─ 공유 또는 주소 복사
        ├─ 관련 단어로 전환 → URL 교체
        └─ 닫기 또는 브라우저 뒤로 가기
             → URL 복원 → 다이얼로그 닫힘 → 시작 요소로 포커스 복귀

[Ctrl/⌘ + K]
   → 검색창 포커스 → 바로 검색 시작
```

## 예외 흐름

- 결과 없음: 검색어 변경과 분위기 필터 초기화를 안내한다.
- 즐겨찾기 없음: 저장 방법과 전체 단어 보기 버튼을 제공한다.
- 사전 네트워크 실패: 선별 결과는 유지하고 재시도한다.
- 잘못된 공유 주소: `word` 파라미터를 제거하고 홈을 유지한다.
- 공유 API 미지원·취소·실패: 주소를 클립보드에 복사한다.
- 저장소 접근 불가: 현재 세션에서만 상태를 유지하고 알림을 제공한다.
