# 말결 유저 플로우

```text
[홈 진입]
   ├─ 오늘의 단어 선택 ─────────────┐
   ├─ 분위기 필터 선택 → 단어 목록 ─┤
   ├─ 찜한 단어 보기 → 저장 목록 ───┤
   └─ 검색어 입력 → 제안/검색 결과 ─┤
                                      ↓
                                [단어 상세 패널]
                                  ├─ 찜 저장/해제
                                  ├─ 링크 공유/복사
                                  ├─ 관련 단어 탐색
                                  └─ 닫기 → 이전 탐색 상태
```

## 예외 흐름

- 검색 결과 없음 → 안내 문구 → 검색어·필터 초기화
- 잘못된 공유 주소 → 기본 홈 유지
- 저장소 접근 불가 → 현재 세션에서만 상태 유지
- 공유 API 미지원 → 클립보드 복사
