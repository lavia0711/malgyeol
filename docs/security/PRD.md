# 말결 보안 강화 PRD

## 목적

현재의 정적 사전 경험을 변경하지 않으면서 요청 헤더 오염, 클릭재킹, 콘텐츠 유형 추론, 공급망 변조에 대한 기본 방어선을 강화한다.

## 목표

- 소셜 메타데이터의 기준 URL을 요청 헤더와 분리한다.
- 모든 애플리케이션 응답에 일관된 보안 헤더를 적용한다.
- GitHub Actions를 검증된 전체 커밋 SHA로 고정한다.
- 의존성 업데이트와 정적 보안 분석을 자동화한다.
- 취약점 비공개 신고 절차를 문서화한다.

## 제외 범위

- 데이터베이스, 로그인, 관리자 API 또는 서버 쓰기 기능 추가
- 현재 검색·즐겨찾기·공유·상세 보기 UX 변경
- 배포 또는 GitHub 원격 저장소 푸시

## 성공 기준

- 임의의 `Host`와 `X-Forwarded-Host`가 OG URL에 반영되지 않는다.
- HTML 응답에 CSP, HSTS, `nosniff`, Referrer Policy, Permissions Policy, 프레이밍 방어가 포함된다.
- CI의 모든 외부 Action이 40자리 SHA로 고정된다.
- 보안 회귀 테스트, lint, 타입 검사, 빌드와 기존 테스트가 통과한다.
