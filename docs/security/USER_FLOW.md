# 보안 강화 유저 플로우

```text
[사용자 요청]
   -> [Sites / Cloudflare TLS 및 인증 경계]
   -> [vinext 라우팅]
   -> [일관된 보안 응답 헤더 적용]
   -> [기존 말결 화면]

[검색어 입력]
   -> [브라우저 정규화]
   -> [전용 Web Worker]
   -> [MiniSearch]
   -> [검색 결과]

[링크 미리보기 요청]
   -> [요청 Host 값은 사용하지 않음]
   -> [고정 Canonical Origin]
   -> [고정 OG 이미지 URL]
```

사용자에게 보이는 탐색, 검색, 즐겨찾기, 공유, 상세 보기 흐름은 변경하지 않는다.
