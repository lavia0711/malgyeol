# 말결 기능 명세서

## 탐색

- 첫 화면에 오늘의 단어, 검색, 8개 분위기 필터, 선별 단어 목록을 배치한다.
- 선별 단어는 분위기를 교차 배치해 첫 화면 편중을 줄인다.
- 처음 32개를 노출하고 `더 보기`를 누를 때마다 32개씩 추가한다.
- 현재 노출 수와 전체 수를 함께 표시한다.
- 즐겨찾기 필터는 저장된 단어 스냅샷을 보여 주며, 비어 있으면 전용 안내와 전체 목록으로 돌아가는 버튼을 제공한다.

## 검색

- 입력값은 NFC 정규화하고 연속 공백과 문장부호를 정리한다.
- 선별 단어는 즉시 검색한다. 전체 사전은 실제 검색어가 입력된 뒤에만 모듈 Web Worker에서 불러온다.
- 사전은 manifest와 compact tuple 청크로 제공한다. 워커는 청크를 순서대로 가져와 MiniSearch 색인에 추가하고, 각 단계의 부분 결과와 진행률을 전달한다.
- 정렬 우선순위는 단어 정확 일치, 접두어 일치, MiniSearch 관련도 순이다.
- 로딩 중에는 현재까지 찾은 결과와 색인 진행 상태를 함께 표시한다.
- 네트워크 오류 시 선별 결과는 유지하고 전체 사전 재시도 버튼을 제공한다.
- 검색어가 없으면 선별 목록을 보여 주고, 결과가 없으면 검색어 변경과 필터 초기화를 안내한다.

## 단어 상세

- 단어, 발음, 품사, 뜻, 편집 해설, 분위기, 추천 용도를 표시한다.
- Radix Dialog 기반 모달로 구현해 포커스 트랩, 배경 비활성화, Escape 닫기, 닫은 뒤 트리거 포커스 복귀를 보장한다.
- `?word=<id>`를 공유 가능한 상세 주소로 사용한다.
- 닫기와 브라우저 뒤로 가기가 URL 및 모달 상태와 동기화된다.
- 잘못된 `word` 값은 제거하고 기본 화면을 유지한다.

## 즐겨찾기와 공유

- 저장 키는 `malgyeol:favorites:v2`이며 각 항목에 렌더링 가능한 최소 `WordEntry` 스냅샷을 저장한다.
- 기존 `malgyeol:favorites:v1` ID 배열은 최초 로드 시 v2로 이전한다. 선별 목록에 없는 ID는 워커 조회로 복원한다.
- 공유 API가 있으면 제목·설명·상세 URL을 전달하고, 없거나 취소·실패하면 URL을 클립보드에 복사한다.
- 저장·복사 결과는 화면 읽기 프로그램이 읽을 수 있는 상태 영역으로 알린다.

## 키보드와 접근성

- `Ctrl + K`와 `⌘ + K`는 검색창에 포커스를 이동한다.
- 검색·필터·카드·모달의 상태와 이름을 보조기술에 제공한다.
- 키보드만으로 모든 핵심 흐름을 완료할 수 있어야 한다.
- 애니메이션 감소 환경을 존중하고 모바일 상세는 바텀시트 형태로 표시한다.

## 데이터·품질·배포

- 데이터 계약은 `WordEntry` 하나로 유지하며 빌드 스크립트가 청크와 manifest를 재생성한다.
- lint, TypeScript, 단위 테스트, 빌드, Playwright E2E, axe 접근성 검사를 CI에서 수행한다.
- 프로덕션 서버에서 HTML이 참조하는 CSS와 JavaScript asset이 200으로 응답하는지 검증한다.
- 비밀 값은 저장소에 커밋하지 않으며 보안 경고가 있는 런타임 의존성은 호환 가능한 범위에서 업데이트한다.
- GitHub 브랜치와 초안 PR을 만든 뒤 검증된 커밋을 Sites에 배포하고 접근 정책을 공개로 전환한다.
