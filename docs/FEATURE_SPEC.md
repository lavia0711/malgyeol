# 말결 기능 명세서

## 탐색

- 첫 화면에 통합 검색, 오늘의 단어, 8개 분위기 필터, 추천 단어를 배치한다.
- 분위기 필터는 복수 선택할 수 있으며 선택한 분위기 중 하나라도 포함한
  단어를 보여준다.
- 찜 보기에서는 저장된 단어만 표시하며, 다시 누르면 전체 목록으로 돌아간다.

## 검색

- 검색 대상은 단어, 뜻, 편집자 해설, 분위기, 추천 용도다.
- 입력과 색인은 NFC 정규화하고 연속 공백과 문장부호를 정리한다.
- 단어 정확 일치, 단어 접두어 일치, MiniSearch 관련도 순으로 정렬한다.
- 검색어가 없으면 선별 단어를 보여주고, 결과가 없으면 필터 초기화와 다른
  검색어를 제안한다.

## 단어 상세

- 단어, 발음, 품사, 뜻, 편집자 해설, 분위기, 추천 용도를 표시한다.
- 상세 패널은 포커스를 내부로 이동하고 Escape 키와 닫기 버튼으로 닫는다.
- `?word=<id>`를 상세 상태의 공유 주소로 사용한다.
- 잘못된 `word` 값은 무시하고 기본 화면을 유지한다.

## 찜과 공유

- 찜 ID는 `malgyeol:favorites:v1` 키로 브라우저 저장소에 보관한다.
- 공유 API가 있으면 제목·설명·공유 주소를 전달하고, 없거나 취소 외 오류가
  발생하면 주소를 클립보드에 복사한다.
- 저장·공유 결과는 화면 읽기 프로그램이 읽을 수 있는 상태 영역에 알린다.

## 데이터와 라이선스

- 데이터 타입은 `WordEntry`를 단일 계약으로 사용한다.
- 사전 원문에서 예문과 미디어는 가져오지 않는다.
- 코드와 편집 데이터의 라이선스를 분리하고 출처를 푸터와 저장소에 표시한다.
