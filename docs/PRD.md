# 말결 PRD

## 제품 정의

말결은 창작자와 이름을 짓는 사용자가 뜻, 분위기, 쓰임을 기준으로 아름다운
한국어 단어를 발견하는 단일 화면 웹사이트다. 사전 검색의 정확성과 편집된
단어 컬렉션의 발견성을 함께 제공한다.

## 핵심 사용자

- 작품과 인물의 이름을 고민하는 작가
- 브랜드와 캠페인 문구를 만드는 기획자·카피라이터
- 뜻과 인상이 좋은 한국어 단어를 찾는 일반 사용자

## 핵심 가치

1. 단어명뿐 아니라 뜻과 분위기로도 검색할 수 있다.
2. 아름다움이라는 주관적 기준을 8개 분위기와 편집자 해설로 설명한다.
3. 마음에 든 단어를 가입 없이 저장하고 바로 공유할 수 있다.

## MVP 성공 기준

- 8개 분위기마다 15개씩 총 120개의 선별 단어가 노출된다.
- 정확 일치, 접두어, 유사 검색이 단어명 우선으로 동작한다.
- 검색 결과에서 상세 확인, 찜, 공유까지 3단계 안에 완료한다.
- 360px 모바일부터 데스크톱까지 핵심 기능을 사용할 수 있다.
- 키보드 포커스, 대화상자 의미 구조, 상태 알림을 지원한다.

## MVP 제외 범위

회원가입, 서버 동기화, 댓글, 사용자 단어 등록, 관리자 화면, 광고, 유료
기능, 커스텀 도메인은 포함하지 않는다.
