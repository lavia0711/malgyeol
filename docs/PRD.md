# 말결 개선 PRD — 활자본 사전

## 제품 정의

말결은 창작자와 이름을 짓는 사용자가 뜻과 분위기를 기준으로 아름다운 한국어 단어를 발견하는 단일 화면 사전 서비스다. 선별한 단어의 발견성과 국립국어원 사전 기반 검색의 정확성을 함께 제공한다.

## 이번 릴리스 목표

말결을 누구나 바로 접속할 수 있는 공개 서비스로 배포하고, 큰 사전을 불러오는 동안에도 화면이 멈추지 않는 검색 경험을 제공한다. 현재 확인된 즐겨찾기 복원, 브라우저 뒤로 가기, 모달 포커스, 단축키 문제도 함께 해결한다.

이번 UI 개편에서는 서비스의 기능을 유지하면서 기존의 둥근 카드, 장식형 그라데이션, 추상 원형 그래픽을 걷어낸다. 화면을 한지 위에 인쇄한 한국어 사전처럼 재구성해 말결만의 편집 정체성을 만든다.

## 시각 방향

- 한지색 바탕, 먹색 본문, 낙관색 강조의 제한된 색 체계를 사용한다.
- 장식보다 활자 크기, 얇은 구분선, 여백과 행간으로 정보 위계를 만든다.
- 검색과 필터는 둥근 패널이 아니라 사전의 색인·찾아보기처럼 보이게 한다.
- 단어 목록은 동일한 카드의 반복이 아니라 번호, 표제어, 뜻, 분위기가 한 행에서 읽히는 사전 목록으로 표현한다.
- 한국적 이미지는 전통 문양의 직접 차용보다 활자본, 낙관, 종이 질감과 세로 조판의 인상으로 전달한다.

## 핵심 사용자

- 작품·브랜드·캠페인 이름을 고민하는 작가와 기획자
- 뜻과 인상이 좋은 한국어 단어를 찾는 일반 사용자
- 마음에 드는 단어를 모아 두었다가 다시 비교하려는 사용자

## 핵심 가치

1. 단어명뿐 아니라 뜻과 분위기로도 빠르게 찾는다.
2. 8개 분위기와 편집된 해설로 단어의 인상을 이해한다.
3. 마음에 든 단어를 계정 없이 저장하고 공유한다.
4. 키보드와 보조기술로도 동일한 핵심 기능을 이용한다.

## 성공 기준

- 검색창 포커스만으로 전체 사전 파일을 내려받지 않는다.
- 검색어를 입력하면 백그라운드 워커가 사전을 점진적으로 색인하며 부분 결과와 진행 상태를 제공한다.
- 선별 단어 120개가 특정 분위기에 편중되지 않고 모두 탐색 가능하다.
- 전체 사전에서 저장한 단어가 새로고침 뒤에도 즐겨찾기 목록에 표시된다.
- 상세 화면의 열기·닫기·브라우저 뒤로 가기와 `?word=<id>` 주소가 항상 일치한다.
- `Ctrl/⌘ + K`, Escape, Tab 이동, 닫은 뒤 포커스 복귀가 동작한다.
- 360px 모바일부터 데스크톱까지 핵심 기능을 사용할 수 있다.
- lint, typecheck, 단위·통합·E2E·접근성 검사가 CI에서 통과한다.
- 360px 모바일과 데스크톱에서 단어 목록의 표제어와 뜻이 카드 장식 없이 명확히 구분된다.
- 기존 검색, 분위기 필터, 즐겨찾기, 공유, 상세 보기 기능의 동작과 접근성 이름이 유지된다.

## 범위

- 압축·분할한 사전 데이터와 Web Worker 기반 점진 검색
- 균형 잡힌 선별 단어 목록과 더 보기
- 즐겨찾기 저장 형식 v2 및 v1 마이그레이션
- 접근 가능한 상세 다이얼로그와 주소·히스토리 동기화
- 키보드 단축키, 오류·로딩·빈 상태 개선
- 의존성 보안 업데이트, 자동 테스트, GitHub CI, 공개 배포
- 활자본 사전 디자인 시스템과 반응형 지면 레이아웃

## 제외 범위

회원가입, 서버 동기화, 사용자 단어 등록, 관리자 화면, 광고, 결제, 커스텀 도메인은 이번 릴리스에 포함하지 않는다.
