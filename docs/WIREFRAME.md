# 말결 와이어프레임

## 데스크톱

```text
┌────────────────────────────────────────────────────┐
│ 말결                              찜한 낱말 ♡ 12   │
├────────────────────────────────────────────────────┤
│ 아름다운 우리말의 결을 발견하세요                  │
│ [ 뜻이나 느낌을 입력해 보세요…              검색 ] │
│ [맑음] [포근함] [설렘] [고요] [빛남] ...           │
├─────────────────────────┬──────────────────────────┤
│ 오늘의 단어             │ 추천 단어                │
│        윤슬             │ 윤슬      아스라이       │
│ 빛에 비치어 반짝이는    │ 미리내    산들바람       │
│ 잔물결                   │ 해사하다  꽃잠           │
│ [자세히] [♡] [공유]     │                          │
├─────────────────────────┴──────────────────────────┤
│ 결과 목록 / 빈 상태                                │
├────────────────────────────────────────────────────┤
│ 사전 출처 · 데이터 라이선스 · 코드 라이선스        │
└────────────────────────────────────────────────────┘
```

## 모바일

헤더 → 소개와 검색 → 오늘의 단어 → 가로 스크롤 필터 → 1열 단어 카드 →
화면 아래에서 올라오는 상세 패널 순으로 배치한다.
